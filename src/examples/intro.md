# Tutorials

In this part of the book we will discuss a few tutorials, to learn about several useful features of the Duckiematrix.

The demos are collected in [this GitHub repository](https://github.com/duckietown/duckiematrix-examples).
In order to use them, the first step is to clone the repository onto your local machine by running:

    git clone https://github.com/duckietown/duckiematrix-examples.git

Each demo needs to be executed from its specific directory, as instructed.
Have fun!
